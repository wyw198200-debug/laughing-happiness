# InsightLite（类 Spotfire 数据分析软件）

这是一个轻量级、前端单页的数据分析工具，提供类似 Spotfire 的核心体验：

- CSV 数据导入
- 交互式数据筛选
- 分组聚合（Sum / Avg / Count）
- 柱状图、折线图、散点图
- 数据表预览

## 快速运行

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 使用步骤

1. 点击“导入数据”上传 CSV。
2. 在“筛选数据”选择列并输入关键词。
3. 在“图表配置”选择 X/Y 轴、图表类型和聚合方式。
4. 点击“生成图表”查看结果。

## 示例 CSV

```csv
区域,产品,销售额,数量
华东,A,1200,10
华东,B,900,7
华南,A,1500,12
华北,C,700,5
```
